The Axiom layer, on the real menu

These eleven are not a demo. They are roblox external/ui/menu_ui.cpp — the host application's menu — rendered by tools/menu_shots.cpp against stub platform callbacks, through the same software rasteriser. Because the layout file touches no Win32 and reads no process memory, the picture below is what the overlay draws, which is the only practical way to review a grid change without the game running. Labels are tracked caps because the widgets shout them; notes and hints are ordinary sentences, because a paragraph in caps is unreadable. The last two are states rather than pages — the ones a page loop cannot reach.
